# PR and commit style

Before writing or editing commit messages, branch names, PR titles, or PR descriptions, read and follow the `pr-and-commit-style` skill at `/Users/danbarclay/.agents/skills/pr-and-commit-style/SKILL.md`. Apply it across all projects.

# Repository delivery

Across all repositories, complete changes by committing the task's changes, pushing the task branch, and opening a pull request or updating the existing pull request. This is Dan's standing preference for all work, including requests phrased only as "commit", unless he explicitly asks otherwise. Do not stop at a local commit or ask again whether to push and create a PR. Include only changes belonging to the task, and leave merging to Dan unless he requests it.
